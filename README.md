# 🥗 HostelNutriAI – AI Hostel Health Companion

HostelNutriAI is an AI-powered web application designed to help hostel and PG students maintain a healthy lifestyle while living away from home.

The platform provides personalized meal recommendations, nutrition tracking, budget management, hydration reminders, and AI-powered health guidance based on hostel food availability.

---

## 🚀 Features

- 🍽️ Daily Hostel Meal Planner
- 🤖 AI Meal Recommendation Assistant
- 💪 Nutrition & Calorie Tracking
- 💧 Water Intake Tracker
- 💰 Monthly Food Budget Planner
- 🛒 Smart Grocery Suggestions
- 📊 Health Dashboard
- 📈 Weekly Nutrition Analytics
- 🏋️ Gym Mode Recommendations
- 📚 Exam Mode Nutrition Tips
- 🔔 Smart Reminders
- 👤 User Profile Management

---

## 🎯 Problem Statement

Hostel students often struggle with:

- Poor nutrition
- Limited food choices
- Budget constraints
- Lack of healthy eating habits
- Missing important nutrients
- Irregular meal timings

HostelNutriAI helps students make healthier decisions using AI-driven recommendations.
